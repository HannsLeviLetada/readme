# The distance between two points

## Description
This program calculates the distance between two points using sqrt() and pow().

## How to run
1. Open the code file in an online editor like Replit or Google Colab, or a desktop app like VS Code.
2. Click the **Run** or **Play** button at the top of the screen to start the program.
3. Type in your numbers when the screen asks for them, and press **Enter** after each one.

## Input needed
You will need to type in 4 numbers total:
* **x1** and **y1** (The starting point coordinates)
* **x2** and **y2** (The ending point coordinates)

## Sample output
```text
Enter x1: 2
Enter y1: 3
Enter x2: 7
Enter y2: 8
The distance between the two points is: 7.07
```
